Compiler

Browser-based code playground

YBY Compiler is your free online environment for learning and executing code in Python, C, C++, and Java. Whether you're a complete beginner or practicing advanced concepts, this compiler provides immediate feedback and visual output to help you understand your code better. Python runs directly in your browser using Pyodide technology, while C, C++, and Java execute through a reliable cloud API.

Unique value: code output, plain-English guidance, uploaded datasets, and chart output all appear together on the same page—no need to switch between tabs or applications.

1
Write or paste code

Choose from Python, C, C++, or Java in the editor. Use it for scripts, homework assignments, practice problems, data analysis projects, or console applications. The syntax highlighting helps you write cleaner code.

2
Attach datasets

Choose CSV, JSON, TXT, TSV, XLSX, or Parquet files and click Attach to Python. Your files are loaded into the Pyodide file system at /home/pyodide/data/filename.csv.

3
Run and visualize

Click Run Code to instantly see text output, errors with clear explanations, code improvement tips, and Python chart previews—all in real time on the same screen.

Supported languages and libraries in this website compiler

Python runs directly in the browser for instant feedback; C, C++, and Java run through the online execution service:

  • Python with standard-library support for core language features, built-in modules, and interactive execution
  • C, C++, and Java through an online execution service for console programs; these languages require internet/API access
  • NumPy for numerical computations and array operations
  • pandas for data manipulation, table analysis, and dataframe operations
  • Matplotlib for creating charts, plots, and data visualizations
  • seaborn for statistical visualization and advanced graphics
  • scikit-learn for machine learning examples and data science projects

How to use uploaded files in Python

  • Step 1: Click the "Upload dataset(s)" button and select your CSV, JSON, TXT, TSV, XLSX, or Parquet files from your computer.
  • Step 2: Click Attach to Python so the browser writes files into the Pyodide file system at /home/pyodide/data/.
  • Step 3: In your Python code, reference the file path. Example: df = pd.read_csv("/home/pyodide/data/YourFilename.csv") or with open("/home/pyodide/data/data.txt") as f: data = f.read().
